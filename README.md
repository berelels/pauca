## Install

| App | |
| --- | --- |
| [**Pauca**](https://play.google.com/store/apps/details?id=app.pauca) | One-time purchase: focus mode, the breathing pause, weather, unlimited profiles, every theme. |
| [**Pauca Lite**](https://play.google.com/store/apps/details?id=app.pauca.lite) | Free: app cards, the drawer, gestures and two profiles. No internet access. |
