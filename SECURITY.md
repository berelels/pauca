# Security policy

To report a vulnerability in Pauca, Pauca Lite or the website, email **gabrieldiasdev@proton.me** with what you found and the steps to reproduce it. If it's about the app, include its version and your phone model. Please don't open a public issue for it, and allow reasonable time for a fix before sharing details publicly.

**Covered:** the latest versions of Pauca and Pauca Lite on Google Play, the code in this repository, and the pages under [cattastudios.com.br/pauca](https://cattastudios.com.br/pauca/).

**What to expect:** Pauca is made by one person, so there's no fixed deadline and no paid bug bounty. Reports are read and valid ones are fixed as soon as possible. If you'd like, you'll be credited once the fix is out.
