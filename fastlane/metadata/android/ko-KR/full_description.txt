Pauca은(는) 휴대폰을 단순 폰(덤폰)에 가깝게 바꿔 줍니다. 앱이 차분한 카드 속 단어가 되고, 이름은 직접 정합니다. 아이콘도, 빨간 배지도, 광고도, 추적도 없습니다.

홈 화면
• 앱을 카드 안의 글자로: 이름 변경, 순서 변경, 그룹 만들기
• 위로 쓸면 모든 앱이 나오는 서랍, 검색과 카테고리 포함
• 아래로 쓸면 알림, 좌우로 쓸면 고른 앱 실행
• 시계, 날짜, 라이트 또는 다크 테마
• 25개 언어 지원

집중 모드
한 번 탭하거나 프로필별로 자동으로:
• 방해 금지 모드, 전화를 받을 사람을 직접 선택
• 알림을 보류했다가 끝날 때 요약으로 표시
• 서랍에는 허용한 앱만 표시, 다른 앱을 열면 홈으로 돌아감
• 흑백 화면 (컴퓨터에서 명령을 한 번만 실행)

잠깐, 숨 고르기
너무 자주 여는 앱을 고르세요. 하루에 정한 횟수를 넘겨 열면 Pauca가 거품을 30초 동안 누르고 숨을 쉬게 한 뒤, 앱을 열지 직접 결정하게 합니다. 추가할 만한 앱도 추천해 줍니다.

날씨
선택한 도시의 기온과 하늘 상태를 홈 화면에 글자로 표시합니다. 인터넷은 이 기능에만 쓰이며 위치는 사용하지 않습니다.

그 밖의 기능
• 개인, 업무, 밤 같은 프로필을 무제한으로, 집중 모드를 자동으로 켜게 할 수도 있습니다
• 테마, 강조 색, 글꼴, 굵기, 정렬, 그리고 흐림과 밝기를 조절한 내 사진
• 버튼, 시계, 상태 표시줄까지 숨기기
• 두 번 탭하여 화면 잠금

개인정보
광고 없음, 추적 없음, 수집하는 데이터 없음. 인터넷은 선택 사항인 날씨에만 쓰이며, 입력한 도시 이름만 사용합니다.

접근성 서비스
Pauca는 접근성 서비스를 선택 가능한 두 가지에만 사용합니다. 두 번 탭하여 화면을 잠그는 것, 그리고 집중 모드에서 목록에 없는 앱이 열리면 홈으로 돌아가는 것입니다. 화면 내용을 읽지 않으며 데이터를 수집하거나 공유하지 않습니다. 꺼 두어도 나머지 기능은 모두 작동합니다.

먼저 Pauca Lite를 무료로 써 보세요. 카드와 설정이 그대로 옮겨집니다. Pauca는 구독 없이 한 번만 결제합니다. 오픈소스(GPLv3), Olauncher를 바탕으로 만들었습니다.
